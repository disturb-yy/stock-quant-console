# 静态页面模块说明

## 1. 文档用途

本文说明当前静态原型 [index.html](/home/jadon/projects/stock-quant/index.html) 的页面模块、展示内容、交互行为和状态边界，用于布局评审。

当前页面是独立原型，不连接真实 API，不代表已经完成生产页面、路由或后端契约。

## 2. 页面定位

- 页面名称：量策 · 股票研究终端
- 默认页面：今日市场 / A 股研究视图
- 主要目标：先查看市场全局，再切换重点股票，最后进入股票目录、同步任务或研究工作区
- 视觉方向：深色数据终端、顶部导航、横向行情快览、紧凑数据面板
- 数据性质：演示数据，页面中已通过“演示数据”标识
- 市场颜色：A 股上涨使用红色，下跌使用绿色；颜色同时配合正负号或文字使用

### 4.11 状态遮罩 StateLayer

代码位置：[index.html:767](/home/jadon/projects/stock-quant/index.html:767)

状态通过 `body[data-state]` 控制：

| 状态 | 页面反馈 |
| --- | --- |
| `normal` | 不显示遮罩，展示默认市场概览 |
| `loading` | 显示加载旋转指示和“正在加载市场数据” |
| `empty` | 显示暂无数据说明和调整筛选条件提示 |
| `error` | 显示请求失败说明，并明确不会自动切换本地数据 |

状态层使用 `aria-live="polite"`，用于辅助技术读取状态变化。

## 6. 响应式规则

| 屏幕宽度 | 当前行为 |
| --- | --- |
| `>= 1180px` | 使用完整双栏工作区、横向指数区和完整顶部操作区 |
| `<= 1180px` | 缩窄内容宽度和搜索控件，保留主要信息 |
| `<= 960px` | 指数区改为两行布局，行情和下方模块改为单列 |
| `<= 720px` | 顶部导航允许换行和横向滚动，搜索区换行，图表高度降低，表格保留横向滚动 |

页面没有通过缩小关键数字来强行容纳所有字段；密集表格在窄屏使用横向滚动。

## 7. 当前原型边界

当前页面明确不包含：

- 真实行情 API
- 登录、权限和账户系统
- 真实自选列表持久化
- 真实分页、排序和后端筛选
- 真实股票目录路由
- 真实同步任务创建、查询和重试
- 真实图表周期切换和数据更新
- 本地存储或接口失败后的静默回退

这些内容需要在后续产品页面、API 契约和验收标准确认后进入实现工作区，不应从本静态原型直接推断为已确认能力。

## 8. 布局评审重点

建议优先评审以下问题：

1. 一级导航与“市场 | 概览 股票 任务”工作台页签之间的层级是否清晰，是否需要进一步合并。
2. “市场脉搏”与四个指数卡的横向密度是否适合主要使用场景。
3. 行情图表与自选观察的左右比例是否满足研究用户的阅读习惯。
4. “热门股票”与“研究入口”是否应该同屏，还是将研究入口移动到股票目录或同步任务页面。
5. “添加自选”是否应该保留在概览首页，还是仅放入股票目录和详情页。
6. 原型状态控制仅用于评审，正式页面是否需要将状态入口改为真实的加载、空态和错误反馈。
